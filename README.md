# Personal Profile Page – Semantic HTML

## 📌 About the Project

This project is a simple **Personal Profile Page** created using **Semantic HTML**.
It demonstrates proper HTML document structure and the use of meaningful semantic elements.

## 🎯 Objective

The main objective is to practice:

* Basic HTML structure
* Semantic HTML elements
* Proper use of headings and sections
* Lists and links
* HTML meta tags and attributes

## 🛠️ Technologies Used

* HTML5

## 📂 Page Sections

The webpage contains:

* **Header** – Name and role/title
* **About** – Short personal introduction
* **Skills** – List of technical skills
* **Contact** – Email, phone number, and LinkedIn profile

## 🧩 Semantic Elements Used

* `<header>`
* `<main>`
* `<section>`
* `<h1>` / `<h2>`
* `<p>`
* `<ul>` / `<li>`
* `<a>`

## 🚫 Restrictions

* No CSS
* No JavaScript
* Only semantic HTML is used

## 🚀 How to Run

1. Clone or download this repository.
2. Open the HTML file in any web browser.
3. View the personal profile page.
